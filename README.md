# Solve Quadratic Equations Python

This example demonstrates how to solve quadratic equations of the form `ax² + bx + c = 0` using Python. It calculates the discriminant to determine the nature of the roots (real or complex) and then applies the quadratic formula to find them.

## Language

`python`

## How to Run

Save the code as `main.py` and run it from your terminal:
`python main.py`
